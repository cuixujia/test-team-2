### 4.2.1 事件一：需求提出与创建
- 锚点：产品需求说明书.md:113-135 => "需求创建成功，进入「待沟通」状态（PENDING），系统生成需求 ID 和 BRD 协作会话"
- 概要：事件类型业务发起事件；干系人业务部门用户（需求发起人）。前置：已登录且有工作空间访问权限、工作空间 ID 有效。输入：工作空间 ID（必填）、需求标题（可选，未提供自动生成默认标题）。应答：需求 ID 与 BRD 协作会话信息。流程：调 HARNESS 建会话（用户同步、Token 获取、工作空间配置、群聊创建），Access Token 存缓存；构建实体入库并记操作日志。结果状态：待沟通（PENDING）。异常分支：参数校验失败、权限不足时拒绝并提示。

### 4.2.2 事件二：需求派发与任务承接
- 锚点：产品需求说明书.md:137-175 => "系统校验派发请求：需求 ID、BRD 文档版本 ID、任务列表必填项完整"

### 4.3.1 需求状态流转
- 锚点：产品需求说明书.md:260-273 => "需求创建后的初始状态，等待需求派发"
- 概要：需求状态仅 3 条迁移：待沟通（PENDING）→处理中（PROCESSING，科技/IT 发起需求派发）；处理中→已完成（COMPLETED，所有关联任务完成）；处理中→已取消（CANCELLED，需求被删除即软删除 valid_flag 置 0）。状态说明：仅待沟通允许修改标题和业务领域；所有有效任务为审核完成或拆解完成时需求自动完成；存在进行中（非已拒绝/已撤回）有效任务时禁止删除。

### 4.3.2 任务状态流转
- 锚点：产品需求说明书.md:275-299 => "仅此状态可被承接、拒绝、转派或撤回"
- 概要：任务 9 状态：待承接、处理中、待审核、审核完成、拆解中、拆解完成、已拒绝、已撤回、业务已拒绝。迁移含待承接→处理中/已拒绝/已撤回；处理中→待审核；待审核→审核完成/业务已拒绝；审核完成→拆解中；拆解中→拆解完成；业务已拒绝→处理中。仅待承接可承接/拒绝/转派/撤回；仅待承接或处理中可改任务标题；拆解完成为终态。支撑 F02 需求完成约束。

### 4.3.3 功能点拆解状态流转
- 锚点：产品需求说明书.md:301-311 => "所有关联功能点拆解完成后，任务进入拆解完成状态（终态）"
- 概要：功能点仅待拆解→已拆解（完成拆解并绑定资产）；已拆解（全部）→任务拆解完成。为 F02 需求自动完成判定（任务为审核完成或拆解完成）的组成条件。

### 4.3.4 状态流转约束
- 锚点：产品需求说明书.md:313-326 => "需求下存在进行中（非已拒绝/已撤回）的有效任务时禁止删除"
- 概要：10 条约束，逐条为：需求完成约束（全部有效任务审核完成或拆解完成则需求自动完成，不回改已完成任务）、删除限制（存在进行中即非已拒绝/已撤回的有效任务时禁止删除）、修改限制（仅待处理或处理中可改标题与业务领域，已完成/已取消禁止）、派发约束（须用最新 BRD 版本，过期版本拒绝）、承接约束（仅待承接可承接/拒绝/转派，不能转派给自己）、审核约束（仅待审核可审核，通过入拆解中，拒绝回处理中）、拆解约束（仅审核完成可开始拆解，全部拆解后到拆解完成且不回退）、任务复用（仅已拒绝/已撤回可复用并清空原因）、待办同步（开关控制，禁用跳过，失败不影响主流程）、消息通知（开关控制，禁用跳过，不影响主流程）。

- 概要：F01 创建入口。输入区：textarea 自适应 70~200px + 工作空间选择器（必选，未选提示「请先选择工作空间；没有合适的空间请先创建」）+ 附件（最多 5 个/单文件 8MB）。提交校验文字非空且空间已选→createBusinessDemand→阶段 Loading（workspace/session/attachments）→跳工作区。列表区：待办（pageSize=50，滚动每页 4 条）/最近事项（按 workspace 分组）。异常：401/403 触发 Electron 登出；附件失败三选项（重试/移除/不带附件发送）。状态码映射 requirement 0=撰写中、1=处理中、2=已完成、3=已取消（与 PRD「待沟通」命名不一致）。

### 13.4 附件上传限制
- 锚点：需求平台前端设计文档.md:1201-1211 => "8 × 1024 × 1024 bytes"
- 概要：创建需求时附件约束：最大 5 个（PROMPT_ATTACHMENT_MAX_COUNT，超出提示「最多添加 5 个文件」）；单文件 8 MB（超出提示具体文件名）；提取文本上限 200,000 字符（超出截断）；支持格式由后端 attachmentCapabilities 返回（md/docx/xlsx/pdf/image）；附件 ID ≤128 字符；预览锚点文本截前 200 字符；批注分页每页 20 条。
