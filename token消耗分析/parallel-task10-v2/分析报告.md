## 四、结论与修复方向

有效项：

- 回合结构修复生效：24 条委派 prompt 全部含回合结构块。
- 子会话轮次持平或下降：索引构建 16→13、TP 生成 B01 23→21、材料质检 14→12。
- bash 权限拒绝 0 次（task6 为 3 次、task7 为 1 次）。

待修项（按优先级）：

1. 运行机环境：修复或确认 ripgrep 可用、确认 show_artifact 工具加载，这两项不解决，提示词层无法止血。
2. 主会话播报回合合并：同一节点的多个回波与台账改动合并处理，压缩 24 轮纯播报。
3. 机验复跑锁定：生成会话"首过即停"执行不到位，需在派发 prompt 或子 agent 约束中强化。
4. 修复质量：TP B01 R2 复检出现新问题，导致额外一轮修复 + 一轮复检。
