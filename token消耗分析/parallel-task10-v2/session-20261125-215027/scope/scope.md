| F03 | M01 需求创建与管理 | 需求台账存档 | 需求及处理记录自动持久化存档并全程记日志，新增独立台账查询入口，支持按需求状态、业务领域、时间范围筛选 | ✅ | 关口 1 确认 |

| F07 | M04 需求进度跟踪 | 需求进度查询 | 按需求 ID 查询并泳道分组展示需求及其关联任务在各阶段的状态分布，只读不改状态 |  |  |
| F08 | M05 需求工作台 | 工作台概览 | 提供五个个人工作泳道视图、各工作空间负载统计，并支持按工作空间分组跳转 BRD/PRD 会话 |  |  |

| F10 | M06 需求资产查询 | 资产血缘查询 | 按资产类型差异化查询 BRD/PRD/FDD 派生与关联关系，组装为需求→任务→功能层级血缘树并标记当前节点 |  |  |
| F11 | M06 需求资产查询 | 相似资产推荐 | 依领域编码（BRD/PRD）或主题活动（FDD）匹配同标签相似资产，去重后按创建时间倒序返回 |  |  |

## 选中功能
- F01 需求创建与受理
- F02 需求状态流转与BRD文档管理
- F03 需求台账存档

## 识别依据锚点
- PRD 5.2 功能矩阵：`产品需求说明书.md:336-359` 列出 F01-F12 全量功能与 M01-M07 模块归属
- PRD 各功能明细：F01 `产品需求说明书.md:391`、F02 `产品需求说明书.md:419`、F03 `产品需求说明书.md:445`
- BRD 功能模块对应：`业务需求说明书.md:28-36`、`:136`；PRD 归并说明 `产品需求说明书.md:336-342`
- 用户选择：关口 1 勾选「模块M01内所有」，含 F01、F02、F03
