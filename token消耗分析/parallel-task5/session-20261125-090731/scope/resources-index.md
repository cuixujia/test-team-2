- 概要：最多 5 个文件；单文件 8MB；提取文本上限 200,000 字符；支持格式由后端 attachmentCapabilities 返回；附件 ID 不超过 128 个字符；批注每页 20 条。

### 13.6 通用交互约束
- 锚点：需求平台前端设计文档.md:1224-1244 => "不一致则提示「已更新，请使用最新卡片」"
- 概要：派发与系统选择工具卡操作前比对 card.time.updated，不一致提示卡片已更新；同一卡片操作互斥；另有转派搜索防抖 300ms、PRD 审核等待超时 2 分钟、待办每页 4 条等约束。
