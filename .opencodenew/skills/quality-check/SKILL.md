# 质检通用规范

本 skill 只放三域共用规则。域规则见【域规范索引】。

## 通用质检纪律

- 质检等于机验加语义检。机验覆盖的格式问题以机验结果为准，通过后不重复入报告；机验 failures 逐条记阻塞并判未收敛。
- 报告只追加，不改写历史轮次。问题只进质检报告，只提建议，不代修产物，不预写方案。
- 落盘后只跑一次机验。failures 归零再送检；failures 非零只修指定项，修完复跑一次。
- 锚点只取 `resources-index` 命中片段。不自建脚本预验，不读脚本源码。
- 每步思考只写结论，不复述规则，不枚举全部条目。回报不复制清单行，不复述机验输出。

### 报告结构

三份报告共用骨架。材料域专用小节见 `quality-check/references/qa-material.md`【待澄清登记】。

```markdown
## R{N}

**检查范围**：本轮检视的资料、功能模块或 TP 与批次

### 问题清单
| 问题编号 | 分级 | 条目 | 问题描述 | 证据锚点 | 建议 |
|---|---|---|---|---|---|
| Q-TP-R1-01 | 重大 | TP-004 | 颗粒度过细 | prd1.md:15 => "……" | 并入 TP-002 |

### 对照表复检
| 问题编号 | 复检结果 | 核对说明 |
|---|---|---|

### 新增条目检查
……

### 收敛判定
Y 或 N，列剩余阻塞与重大项
```

| 字段 | 要求 |
|---|---|
| 检查范围 | 本轮实际检视的资料或条目，分批时逐批列出 |
| 问题清单 | 附证据锚点；编号 `Q-M-R{N}-{seq}`、`Q-TP-R{N}-{seq}`、`Q-TC-R{N}-{seq}`；分级见【语义判据】 |
| 对照表复检 | R2+ 填写，只查问题清单中的编号 |
| 新增条目检查 | R2+ 填写，只查本轮新增条目 |
| 收敛判定 | 阻塞与重大均为 0 才判 Y。一般项不阻止收敛，遗留项记 `state.md`。判定语写「阻塞 N / 重大 N / 一般 N；收敛判定 Y/N；一句理由」 |

材料域的待澄清问题与资料缺口按 `quality-check/references/qa-material.md`【待澄清登记】追加，不进入共用骨架。

### 语义判据

TP 与 TC 语义检视共用。机验覆盖的格式问题不重复列入。

| # | 维度 | 判定要点 | 分级参考 |
|---|---|---|---|
| 1 | 展开充分性 | 抽查 `用例展开重点` 项数与正反边界分布；用例均一化且不符客观分支即整批凑数 | 偏少重大；均一化阻塞 |
| 2 | 臆造检测 | `原文依据` 须有原文或澄清支撑；`方法论补充` 只判对象锚点、知识链发散、静默生成与是否新增字段 | 阻塞 |
| 3 | 排序 | TP 同功能相邻，功能级在前，场景级收尾；TC 跟主 TP，段内正、反、边界 | 段内乱序一般；功能段被打断重大 |
| 4 | 澄清 | `澄清依据` 语义须与 C 编号一致；`C-编号(默认)` 须确认默认口径未引入新风险 | 误用阻塞；风险重大 |
| 5 | 依据缺口 | 缺失维度或小类是否有对应 TP 或 TC；`依据类型` 逐条标注 | 缺失重大 |

### 锚点格式

索引与清单中的 `出处锚点` 统一按此写，脚本按此验真。

| 原文类型 | 合法格式 |
|---|---|
| md、txt、csv | `文件名:起始行-结束行 => "摘抄"` |
| docx | `文件名#章节标题 => "摘抄"` |
| xlsx | `文件名#Sheet名!单元格 => "摘抄"` |

1. 摘抄须是定位行的连续原文，尽量 50 字以内。改写或缩合即问题。
2. 摘抄不得含半角双引号、竖线或 ` => `。多锚点用 ` ;; ` 分隔，分隔符用 ASCII `-`。
3. md 行区间须 `1 ≤ 起始 ≤ 结束 ≤ 总行数`。docx 标题须对应 Heading 段落。禁裸格式 `文件名:行号`。
4. 整行锚点不得用反引号包裹，否则摘抄以反引号结尾，解析判非法。

### 机验说明

`verify_citation.py` 在语义检视前执行。失败项记阻塞，通过后不重复入报告。

1. 锚点：格式见【锚点格式】。归一空白后做子串比对，末尾 `...` 作截断标记。`--index` 验索引，`--tp` 与 `--tc` 验清单。
2. 表格：缺列、文件缺失或为空即 `fatal`。竖线不闭合的行被跳过，首表外数据行不可见即 warnings。
3. 值域与关联：`类型`、`测试维度`、`所属小类`、`测试方法`、`依据类型` 取白名单 TP_DIMENSIONS、TC_METHODS、BASIS_TYPES。`关联TP` 与 `关联业务功能` 逐字一致，编号格式合法。
4. 澄清依据：` ;; ` 分隔校验 `C-\d+`，可带 `C-编号(默认)`，须在 `state/clarifications.md` 存在。`-` 或空表示无澄清。
5. 数量守恒：`--tp` 与 `--tc` 同参时逐 TP 统计直属 TC 数 M。`M<2` 判 failures，`M=0` 由 warning 承载。`依据类型` 非空合法，两类均须验真 `出处锚点`。

退出码 0 表示无失败，1 表示有失败，2 表示用法或致命错误。payload 含 `fatal_messages`。

## 域规范索引

本 skill 内 `references/...` 均指 `SKILLS_ROOT/quality-check/references/...`。

| 域 | 规范文件 | 适用任务 |
|---|---|---|
| 材料 | `references/qa-material.md` | 资料质检、索引构建、索引修复 |
| TP | `references/qa-tp.md` | TP 质检、TP 生成、TP 修复 |
| TC | `references/qa-tc.md` | TC 质检、TC 生成、TC 修复 |

域规范必须与 `quality-check` 在同一步并行加载，不得分轮。
