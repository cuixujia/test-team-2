# 通用测试规则

> 本文件提供通用测试规则，任何业务系统均可直接套用。
> 规则按"大类 → 测试维度 → 小类 → 关注点"四级结构组织，与《测试维度定义》中的大类和维度名称保持一致。

---

## 一、功能测试

### 1. 基础功能

#### 1.1 功能正确性

验证单个功能点的输入输出与预期一致。

| 关注点 | 说明 |
|--------|------|
| 正向主路径 | 按需求描述的正常使用流程操作，验证结果符合预期 |
| 输入输出一致性 | 输入合法数据时，系统产出（页面展示、数据库记录、下游通知等）与需求一致 |
| 即时反馈 | 操作后系统给出明确的成功/失败反馈，不出现无响应或静默失败 |

#### 1.2 字段校验（输入域测试）

> 涉及用户输入的每个字段/参数

**第一步：梳理输入域四要素**

对每个输入字段提取以下四要素作为测试依据：

| 要素 | 说明 | 示例 |
|------|------|------|
| **类型** | 字段的底层数据类型 | 字符串、整数、小数、日期、布尔、枚举等 |
| **合法范围** | 允许的最小值到最大值区间 | 金额：0.01~99,999,999.99；年龄：1~150 |
| **是否必填** | 该字段是否允许为空 | 必填 / 选填 |
| **格式规则** | 字段的格式约束 | 正则表达式、固定长度、特定字符集等 |

**第二步：分析方法**

| 方法 | 策略 |
|------|------|
| **等价类划分** | 有效等价类：符合所有约束条件的输入集合，每个至少取一个代表值；无效等价类：违反某一项约束条件的输入集合，每种违规类型各取一个代表值，不叠加多种错误 |
| **边界值分析** | 下边界（最小值、最小值-1）、上边界（最大值、最大值+1）、内边界（最小值+1、最大值-1） |

**第三步：六大固定测试场景**

**（1）空场景**

| 测试项 | 关注点 |
|--------|--------|
| 必填字段为空 | 必填字段传 null / 空字符串 / 空格，应拦截并提示 |
| 选填字段为空 | 选填字段为空时应正常处理，不影响业务逻辑 |
| 全部字段为空 | 所有输入均为空的极端情况 |

**（2）长度场景**

| 测试项 | 关注点 |
|--------|--------|
| 最小长度 | 恰好为最小允许长度的值 |
| 最大长度 | 恰好为最大允许长度的值 |
| 超长输入 | 超过最大允许长度 1 位及更多；系统截断或拒绝 |
| 零长度 | 空字符串与 null 的区别处理 |

**（3）数值场景**

| 测试项 | 关注点 |
|--------|--------|
| 正数/负数/零 | 按业务规则判断是否允许 |
| 小数精度 | 超出规定小数位数时的舍入或拒绝 |
| 极大/极小值 | 接近数据类型上限/下限的值 |
| 科学计数法 | 输入 1e5 等特殊数值格式的处理 |

**（4）字符场景**

| 测试项 | 关注点 |
|--------|--------|
| 纯中文 | 中文字符的存储和展示 |
| 纯英文 | 大小写字母混合 |
| 特殊字符 | `@#$%^&*(){}[]\|;:'",.<>?/~` 等 |
| 空格处理 | 首尾空格、中间空格、连续空格 |
| SQL注入字符 | `' OR 1=1 --` 等注入尝试被拦截 |
| XSS字符 | `<script>alert(1)</script>` 等被过滤 |

**（5）格式类**

| 测试项 | 关注点 |
|--------|--------|
| 身份证号 | 18位含校验码合法性；15位旧证兼容；常见错误号段 |
| 手机号 | 11位、以1开头、第二位合法号段；虚拟运营商号段 |
| 银行卡号 | Luhn 算法校验；卡BIN识别；长度合规 |
| 日期格式 | YYYY-MM-DD、YYYY/MM/DD 等约定格式；非法日期（如2月30日） |
| 金额格式 | 千分位分隔符；货币符号；负号位置 |

**（6）枚举类**

| 测试项 | 关注点 |
|--------|--------|
| 有效枚举值 | 枚举定义中的所有合法值逐一验证 |
| 无效枚举值 | 不在枚举定义中的值被正确拦截 |
| 大小写敏感 | 枚举值的大小写变体处理 |
| 新旧枚举兼容 | 枚举值变更后的历史数据兼容性 |

**第四步：判定规则**

| 判定类型 | 规则 |
|---------|------|
| 有效输入 | 满足类型 + 合法范围 + 必填要求 + 格式规则 → 进入正常业务流程 |
| 无效输入 | 违反任一约束 → 返回明确的错误码和错误提示，**不进入业务处理**，不产生任何副作用 |
| 错误提示规范 | 错误信息指向具体违规字段和原因，不使用通用模糊提示 |

**第五步：输入域联动**

| 联动类型 | 关注点 |
|---------|--------|
| 字段间依赖 | 字段A的值影响字段B的合法范围或必填状态 |
| 条件显示 | 某些字段根据前置选择动态显示/隐藏；隐藏字段不应出现在请求报文中 |
| 级联校验 | 多字段组合后的整体校验（如开始日期 ≤ 结束日期） |

**第六步：前后端校验一致性**

| 检查项 | 关注点 |
|--------|--------|
| 前端校验 | 页面/客户端层面的即时校验反馈 |
| 后端校验 | 服务端接口的独立校验（不可信任前端校验） |
| 绕过前端直调接口 | 跳过前端直接调用后端接口时，后端仍能正确拦截非法输入 |
| 校验规则一致 | 前后端的校验规则（范围、格式、必填）完全一致，不允许出现前端通过但后端拒绝的不一致情况 |

#### 1.3 业务规则

验证需求中明确的业务规则被正确实现。

| 关注点 | 说明 |
|--------|------|
| 计算公式 | 需求中涉及的计算逻辑（合计、分摊、折扣等）结果正确 |
| 阈值判断 | 达到/未达阈值的分支处理正确 |
| 策略执行 | 优惠、折扣、积分、等级等策略按规则生效 |
| 定时/周期规则 | 定时任务、周期执行的触发时机和执行结果正确 |

#### 1.4 异常与错误处理

验证异常输入、操作失败、依赖异常时系统的处理与提示。

| 关注点 | 说明 |
|--------|------|
| 空值/非法值 | 输入不符合预期的数据时，系统给出明确错误提示，不崩溃 |
| 依赖不可用 | 下游服务或外部接口不可用时，系统有降级或友好提示 |
| 操作失败 | 操作执行失败时回滚到安全状态，不留下脏数据 |
| 错误提示友好性 | 错误信息用户可读，不使用技术术语或堆栈信息 |
| 不影响其他功能 | 某一功能异常不影响系统中其他功能的正常使用 |

### 2. 业务流程

#### 2.1 主流程

验证核心业务路径的端到端正常流转。

| 关注点 | 说明 |
|--------|------|
| 端到端链路 | 从入口到终态的完整链路可走通，各环节衔接顺畅 |
| 关键节点产出 | 每个环节的关键产出（数据记录、状态变更、消息通知）正确生成 |
| 正向完成 | 正常条件下流程顺利完结，最终状态和结果符合预期 |
| **操作顺序依赖** | 有先后依赖关系的操作必须按序执行；跳过前置步骤时应被拦截 |
| **时间窗口控制** | 只能在有效时间窗口内执行的操作（如工作日、营业时间内）；非有效时段应拦截 |
| **到期/截止时点** | 到期日、截止日期等关键时点的判定逻辑正确 |

#### 2.2 分支流程

验证各条件分支与替代路径。

| 关注点    | 说明               |
| ------ | ---------------- |
| 条件分支   | 不同条件下的分支走向正确     |
| 兜底路径   | 无匹配条件时的默认/兜底处理正确 |
| 异常处理分支 | 流程中异常情况的处理分支正确   |
| 跳转逻辑   | 分支间的跳转条件和目标正确    |

#### 2.3 状态流转

> **前置通用规则 · 状态闭环**（涉及交易/接口时必测，优先级"高"）

验证对象状态机及各状态间转换条件。

| 关注点 | 说明 |
|--------|------|
| 状态流转完整性 | 每个状态都有明确的进入条件和退出条件；不存在无法到达的孤立状态 |
| 状态互斥 | 同一时刻只能处于一个有效状态；不允许出现矛盾状态组合 |
| 合法转换 | 每条允许的转换边都能正确触发 |
| 非法转换拦截 | 不允许的状态跳变被正确拦截并给出提示 |
| 终态不可逆 | 已完成的终态不允许回退到中间状态 |
| 异常状态恢复 | 操作失败后状态回滚到初始状态；支持人工干预修复异常状态 |
| 状态与操作匹配 | 各状态下允许执行的操作集正确；不允许的操作被明确拦截并给出提示 |
| 超时自动流转 | 需要超时自动流转的场景，计时和触发准确 |
| 状态持久化 | 系统重启、刷新后状态保持 |

#### 2.4 流程衔接与回退

验证跨环节衔接、撤销、回退与重走。

| 关注点 | 说明 |
|--------|------|
| 上一步/下一步 | 流程导航按钮行为正确 |
| 撤销 | 撤销操作将状态和数据恢复到撤销前 |
| 驳回 | 驳回后数据保留且可修改重新提交 |
| 回退重填 | 回退后之前填写的数据按需求保留或清空 |
| 跳转后返回 | 跳转到关联页面操作后再返回，当前流程上下文保持 |

**审批流程专项覆盖**（如涉及审批流程）：

| 场景 | 关注点 |
|------|--------|
| 单级审批同意 | 审批人同意后流程继续或完成 |
| 多级审批逐级同意 | 各级审批人依次同意后流程完成 |
| 会签模式 | 所有审批人均同意后完成；任一审批人拒绝后的处理 |
| 或签模式 | 任一审批人同意后跳过其余节点 |
| 审批拒绝 | 拒绝后流程终止，拒绝理由记录和可追溯 |
| 审批驳回 | 各级驳回、驳回至发起人、驳回至指定节点 |
| 审批撤回 | 发起人在不同阶段撤回的权限变化 |
| 审批转交 | 转交他人审批、超时自动转交 |
| 审批人不可用 | 审批人离职、请假、无权限时的处理 |
| 重复审批与并发 | 多人同时审批同一单据的处理 |

**授权/复核流程专项覆盖**（如涉及）：

| 场景 | 关注点 |
|------|--------|
| 复核同意 | 复核人同意后业务生效，关联状态变更 |
| 复核拒绝 | 拒绝后业务退回或保留草稿 |
| 授权同意 | 权限立即生效，审计日志记录 |
| 授权拒绝 | 权限不变，可重新申请 |
| 权限范围校验 | 越权申请、超范围授权被拦截 |
| 权限冲突检测 | 互斥角色、重叠权限检测 |
| 授权撤销与过期 | 主动回收、到期自动失效 |

### 3. 界面与体验（UI/UX）

> 仅当需求涉及前端界面时输出；纯接口或批量作业需求省略。

| 检查项 | 关注点 |
|---------|--------|
| **界面布局合理性** | 页面整体布局符合设计规范；元素排列整齐，无重叠、错位、截断；响应式适配不同分辨率；操作流程的视觉引导清晰 |
| **字段展示正确性** | 所有字段标签名称与需求一致；字段类型匹配（文本/数字/日期/下拉等）；必填标识明确标注；默认值展示正确；只读/可编辑状态符合业务规则 |
| **数据展示准确性** | 列表数据分页正确；排序规则生效；筛选条件生效；金额、日期等格式化处理正确；千分位、小数位数符合规范 |
| **交互元素状态** | 按钮启用/禁用状态正确；链接跳转目标正确；弹窗/提示框文案准确；Tab 切换内容加载正确 |
| **提示信息** | 成功/失败/警告提示语明确；错误提示指向具体原因；帮助说明文字完整 |

**详细展开：**

| 子维度 | 关注点 |
|--------|--------|
| 布局与适配 | 分辨率、多端适配、响应式、滚动、溢出、遮挡、弹窗层级 |
| 元素交互 | 点击/长按/滑动、禁用态、加载态、弹窗确认、快捷键、焦点 |
| 文案与多语言 | 文案正确性、错别字、占位符残留、多语言翻译、日期/货币/时区格式 |
| 视觉与易用性 | 风格统一、配色、图标、间距、加载骨架、空状态、易访问性 |
| 表单体验 | 必填项标识清晰、placeholder 准确、辅助输入组件功能正常、重置取消确认 |
| 键盘与快捷键 | Tab 键焦点顺序合理、Enter 提交、Esc 关闭弹窗、焦点环可见 |
| 无障碍访问 | 图片 alt 文本、颜色对比度、色盲友好（不单纯依赖颜色传递信息） |
| 国际化 | 多语言切换后文案/日期/数字格式跟随变化、布局不因文案长度错乱 |

**按钮功能验证清单**（功能测试维度中逐项覆盖）：

| 按钮类型 | 验证要点 |
|---------|---------|
| 提交/保存 | 数据正确写入；必填项拦截；防重处理（置灰/Loading/二次确认） |
| 取消/返回 | 回到上一页或关闭弹窗；已填数据确认丢弃；不产生数据变更 |
| 删除 | 单个/批量删除正确；二次确认；列表自动刷新 |
| 编辑/修改 | 正确加载已有数据；保存后更新生效；并发修改处理 |
| 查询/搜索 | 按条件查询准确；多条件组合；空条件查全部；无结果空状态提示 |
| 重置 | 表单恢复到初始状态；筛选条件清空后重新查全部 |
| 导入/导出 | 文件格式校验、模板下载、导入反馈、错误行定位；导出完整性 |
| 新增/创建 | 正确跳转或弹出新建表单；初始值为空或合理默认值 |
| 详情/查看 | 展示数据与列表一致；详情页只读不可编辑 |
| 审核/审批 | 同意、拒绝、驳回等操作正确执行及后续流程触发 |
| 下载/预览 | 文件下载完整性；预览内容与数据一致 |
| 打印 | 打印内容与页面数据一致；打印布局正确 |
| 刷新/同步 | 数据实时更新；手动与自动刷新行为差异 |
| 分页 | 上一页/下一页/首页/末页/跳页正确；页码与实际页数一致 |
| 展开/收起 | 折叠面板、树形节点、详情展开交互正确 |
| 排序 | 列头点击升序/降序切换；多字段排序优先级 |
| 权限控制 | 无权限时按钮隐藏、置灰或提示无权限 |
| 按钮状态联动 | 根据业务状态动态显示/隐藏或启用/禁用 |

### 4. 数据校验

#### 4.1 数据正确性

验证数据的值、精度与展示是否准确。

| 关注点 | 说明 |
|--------|------|
| 字段值 | 数据库中存储的值与预期一致，无截断、乱码或精度丢失 |
| 精度与舍入 | 金额、百分比等数值的小数位数和舍入规则正确 |
| 默认值 | 未显式赋值时采用正确的默认值 |
| 统计汇总 | 合计等于分项之和，无四舍五入误差累积 |
| 前后端一致 | 页面展示数据与后端返回数据一致 |

#### 4.2 数据一致性

> **前置通用规则 · 数据一致性**（涉及交易/接口时必测，优先级"高"）

验证跨模块、跨表、多副本间的数据一致。

| 关注点 | 说明 |
|--------|------|
| 操作前后一致性 | 操作执行前后数据变化符合预期；操作失败时数据回滚 |
| 主子表关联 | 主表与子表、父记录与子记录的关联关系正确 |
| 缓存与 DB | 缓存中的数据与数据库保持一致，缓存过期后能正确刷新 |
| 读写分离 | 写操作后读操作能看到最新数据（考虑最终一致性窗口） |
| 消息最终一致 | 基于消息队列的异步操作最终达到一致状态 |
| 数据迁移 | 数据迁移后源和目标一致，无丢失或重复 |
| 跨模块一致 | 同一数据在不同功能模块中的展示和处理结果一致 |
| 数据更新同步 | 数据变更后相关页面的缓存刷新和实时性 |
| 分页与筛选 | 分页总数、筛选结果数量与实际数据量一致，无遗漏或重复 |
| 导入/导出一致 | 导出数据与源数据一致，重新导入后数据不丢失、不重复 |
| 总分核对 | 汇总统计数据与明细加总一致 |
| 差错发现机制 | 数据不一致时有明确的差错记录和告警；支持差错查询和定位 |
| 差错处理流程 | 支持自动和人工两种处理方式；处理操作留痕可追溯 |

#### 4.3 数据隔离

验证多用户/多租户间数据互不干扰。

| 关注点 | 说明 |
|--------|------|
| 水平越权防护 | 用户 A 不能通过改 ID 等方式访问用户 B 的数据 |
| 租户隔离 | 多租户环境下各租户数据完全隔离 |
| 查询范围限制 | 查询结果仅限于当前用户/角色的数据权限范围 |

#### 4.4 数据存储与持久化

验证数据的入库、落库、查询与导出。

| 关注点 | 说明 |
|--------|------|
| 落库正确性 | 操作完成后数据正确写入数据库 |
| 查询检索 | 按条件查询能准确找到目标数据 |
| 排序分页 | 排序规则正确，分页导航无误 |
| 导入导出 | 批量导入数据完整入库；导出文件内容与列表一致 |
| 批量操作 | 大批量操作的原子性和完整性 |

### 5. 权限控制

#### 5.1 身份认证

验证登录与身份凭证的有效性。

| 关注点 | 说明 |
|--------|------|
| 登录态 | 登录后能正常使用功能，未登录时受限功能不可访问 |
| Token 过期 | Token 过期后请求返回 401，需重新登录 |
| 多点登录 | 多设备/浏览器同时登录的行为符合需求（允许或踢下线） |
| 单点登录 | SSO 集成场景下的登录和登出正确 |
| 密码策略 | 密码复杂度、定期更换、连续失败锁定等策略生效 |
| 未登录/过期会话 | 未登录状态和 Token 过期后的访问拦截 |

#### 5.2 功能权限

> **前置通用规则 · 权限控制**（涉及交易/接口时必测，优先级"高"）

验证不同角色的功能与操作范围。

| 关注点 | 说明 |
|--------|------|
| RBAC/ABAC 权限矩阵 | 各角色的功能权限按矩阵配置正确生效 |
| 菜单/按钮可见性 | 无权限时对应的菜单项隐藏、按钮置灰或不可见 |
| 垂直越权 | 低权限用户不能访问高权限功能 |
| 操作权限 | 各角色对新增、查询、修改、删除、导出、审批等操作的权限控制 |
| 管理员权限分级 | 超级管理员与普通管理员权限边界清晰；敏感操作需高级权限 |

#### 5.3 数据权限

验证不同身份可见的数据范围。

| 关注点 | 说明 |
|--------|------|
| 数据范围 | 仅本人数据、本部门数据、全部数据等范围正确；用户只能查看和操作其权限范围内的数据 |
| 行级/列级权限 | 行级过滤和列级脱敏正确 |
| 数据脱敏 | 敏感字段（如手机号中间四位）脱敏显示 |
| 客户数据隔离 | 客户只能查看自己的数据；操作员只能操作经授权的客户数据 |
| 跨租户/跨组织隔离 | 多租户环境下数据完全隔离；不得通过任何途径越权访问其他租户数据 |

#### 5.4 操作审计

验证敏感操作的审批、留痕与防重放。

| 关注点 | 说明 |
|--------|------|
| 审批流 | 敏感操作需经过审批流程 |
| 二次确认 | 高风险操作（如删除）需二次确认 |
| 审计日志 | 操作人、时间、内容、IP 等信息完整记录 |
| 防重放 | 敏感操作不可被重放攻击 |

#### 5.5 越权操作

验证水平/垂直越权与提权漏洞。

| 关注点 | 说明 |
|--------|------|
| 水平越权 | 同角色跨用户访问被拒绝 |
| 垂直越权 | 低权限调高权限接口被拦截 |
| 提权 | 普通用户不能通过任何手段获取管理员权限 |
| ID 可遍历 | 遍历 ID 访问其他用户资源被拒绝 |
| 越权修改 | 修改不属于自己权限范围的数据被拦截 |

### 6. 接口 API 测试

#### 6.1 接口契约

> **前置通用规则 · 报文契约**（涉及交易/接口时必测，优先级"高"）

验证接口入参出参与约定一致。

| 关注点 | 说明 |
|--------|------|
| URL/方法 | 接口地址和 HTTP 方法符合约定 |
| 字段名/类型/必填 | 请求和响应字段名称、类型、必填性与文档一致 |
| 返回码 | 成功和失败均返回约定的错误码体系，含义明确 |
| 版本兼容 | 新老版本接口兼容；报文版本升级时向下兼容；废弃字段处理策略明确 |
| 字段映射正确性 | 上下游系统间字段映射关系正确；枚举值转换无误 |
| 边界值报文 | 空字符串、null、极长字符串、特殊字符等边界值的处理符合约定 |

#### 6.2 参数校验

验证接口入参的合法性与边界。

| 关注点 | 说明 |
|--------|------|
| 必填校验 | 必填字段缺失时返回参数错误 |
| 类型校验 | 字段类型不符时拦截 |
| 长度/格式 | 超长、格式错误时拦截 |
| 枚举校验 | 非法枚举值返回参数错误 |
| 特殊字符 | SQL 注入、XSS 等特殊字符被过滤 |

#### 6.3 业务逻辑

验证接口背后的业务规则与数据处理。

| 关注点 | 说明 |
|--------|------|
| 业务规则 | 接口执行的业务逻辑正确 |
| 数据增删改查 | 操作后数据变更符合预期 |
| 状态变更 | 接口触发的状态变更正确 |
| **幂等性** | 重复提交同一请求不产生重复效果；相同参数连续提交多次仅产生一笔有效交易，后续返回原交易结果；客户端因网络超时而重试时服务端不产生重复交易 |
| **幂等键校验** | 基于交易流水号/请求 ID 等幂等键去重；幂等键冲突时返回明确提示 |
| **跨渠道幂等** | 同一笔业务通过不同渠道发起，按业务规则判断是否应幂等拦截 |

#### 6.4 异常处理

验证异常与依赖故障时的接口表现。

| 关注点 | 说明 |
|--------|------|
| 依赖不可用 | 下游服务不可用时返回明确错误码 |
| 超时 | 超时返回超时错误，不hang住 |
| 限流 | 超过限流阈值时返回 429 |
| 错误码 | 错误码含义明确，不返回内部异常信息 |
| 降级 | 非核心依赖故障时有降级策略 |

### 10. 可靠性与稳定性

#### 10.1 故障恢复

验证故障与异常条件下的恢复能力。

| 关注点 | 说明 |
|--------|------|
| 容错 | 单点故障不影响整体服务 |
| 故障恢复 | 服务宕机后能自动或手动恢复 |
| 降级熔断 | 非核心功能故障时降级，核心功能不受影响 |
| 灾备 | 灾难场景下的数据恢复和业务接管 |
| **网络闪断** | 交易发起后网络连接瞬间断开又恢复；服务端收到请求但客户端未收到响应，客户端重试后的幂等处理 |
| **超时** | 请求处理超过约定超时时间；客户端超时后发起查询或取消；服务端超时保护机制（如异步处理兜底） |
| **报文丢包** | 请求/响应报文在传输过程中丢失；TCP 层面的重传和业务层面的补偿机制 |
| **报文乱序** | 多笔连续交易的响应报文到达顺序与发送顺序不一致；系统按正确顺序处理，不产生数据错乱 |
| **重复报文** | 网络层或中间件导致同一请求被重复发送；服务端基于幂等键去重 |
| **同步回调超时** | 上游发起交易后等待下游回调，下游处理超时未返回；上游侧的状态挂起和超时处理策略 |
| **异步回调延迟** | 下游系统在非实时时间内完成处理并回调通知上游；上游收到延迟回调后能正确更新状态 |
| **回调失败重试** | 下游回调通知上游时上游不可用，下游的重试机制和最终一致性保证 |
| **回调丢失补偿** | 回调消息完全丢失时的对账发现和差错修复流程 |
| **重复回调** | 下游因不确定上游是否收到而重复发送回调；上游幂等处理，不重复执行 |

#### 10.2 健壮性

验证异常与极端条件下的表现。

| 关注点 | 说明 |
|--------|------|
| 资源耗尽 | 磁盘写满/连接耗尽时优雅处理 |
| 内存泄漏 | 长时间运行无内存泄漏 |
| 异常输入 | 极端异常输入不导致系统崩溃 |
| 长时间运行 | 7×24 运行稳定 |
